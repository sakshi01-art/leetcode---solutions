# DSA Problem-Solving Workflow

This repository is a learning and revision space for LeetCode and DSA practice in C++.

## Repeatable Workflow

1. Read the problem and identify the input/output contract.
2. Write down a straightforward approach.
3. Check edge cases before coding.
4. Implement a clean C++ solution.
5. Test with small examples and boundary cases.
6. Analyze time and space complexity.
7. Record the main pattern or data structure for revision.

## Current Learning Direction

The repository currently emphasizes arrays, hashing, strings, two pointers, stack, linked list, binary search, and introductory dynamic programming, with trees and graphs planned next.

## Revision Habit

For each solved problem, keep the explanation short enough to revisit quickly:
- problem idea
- key observation
- approach
- complexity
- common edge case
