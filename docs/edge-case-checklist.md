# DSA Edge-Case Checklist

A short checklist to use before submitting a C++ problem solution.

## Checklist

- Check empty input and single-element input.
- Check duplicate values and repeated states.
- Check the smallest and largest valid values.
- Verify loop boundaries and off-by-one cases.
- Confirm the target/result when no valid answer exists.
- Review time and space complexity before submission.

## Practice habit

**Understand → Plan → Code → Test → Analyze → Revise**

This checklist is part of the repository's ongoing DSA practice workflow.
